Project Description

Ka-Partner App (Smart DMS) — Retailer Mobile app.
The Smart Ka-Partner App provides more than what you need to make your loading business easier to manage and more convenient in load selling. With this app, you won't need to memorize all the keywords and access codes to load up your suki. Our menus are readily available — in just a few clicks, you'll be able to load your suki.

Features

  • Zero-rated: no charge in using the app
  • Registration for existing retailers — paperless
  • Load Wallet: Smart, TNT, and other telco products (PLDT, Meralco, Cignal)
  • Product Offer descriptions to guide suki decisions
  • Notebook: view BENTA at KITA and all loading transactions
  • Security PIN protection for the load wallet
  • Suki List for saving loyal customers' mobile numbers
  • Tools & Services: set wallet threshold for timely replenishment
